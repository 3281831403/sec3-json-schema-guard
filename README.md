接口按约定校验请求体，但 schema 里没写额外字段禁止，攻击者塞进来的字段一路带进了数据库：未声明字段必须拒绝，必填字段缺失必须拒绝，数值边界必须包含端点，字符串长度与枚举必须逐条校验，嵌套对象与数组必须递归校验，校验失败必须给出路径，批量校验的各次请求必须彼此独立。任何未通过校验的请求体都不会进入后续流程，同一请求连续两次校验的结果必须完全一致。
